heart.glb
=========

"Realistic Human Heart" by neshallads
https://sketchfab.com/3d-models/realistic-human-heart-3f8072336ce94d18b3d0d055a1ece089
Licensed under Creative Commons Attribution 4.0 (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

Downloaded from Sketchfab as GLB (2k textures). Used unmodified; CardioVision bakes the node
transforms, fits its own risk-coloured coronary tree and perfusion territories onto the surface
at runtime (frontend/src/components/specimenAnatomy.ts), and overrides metalness to 0.

If this file is missing, the app falls back to its procedural (schematic) heart.
